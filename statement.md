# CampusConnect — Project Statement

## Problem Statement
Campus services such as hostel maintenance, lost-and-found reporting and event registration are frequently handled through disconnected/manual channels. This makes tracking, communication and administration difficult.

## Scope
CampusConnect covers authentication, student records, hostel complaints, lost/found items, claims and campus events in a JavaFX desktop application backed by MySQL.

## Target Users
- Students
- Campus administrators

## Proposed Solution
A role-based desktop platform where students can access campus services from one dashboard and administrators can manage records through dedicated management screens.

## High-Level Features
- Secure login
- Student profile
- Complaint lifecycle
- Lost/found and claim workflow
- Event registration with capacity control
- Administrative dashboard and CRUD

## Expected Outcomes
A runnable academic project demonstrating Java OOP, MVC, JDBC/MySQL, CRUD, validation, exception handling, collections, password security, testing and JavaFX GUI design.
